# chiller-dashboard

## 📊 Project Overview

**chiller-dash** is a real-time Power BI dashboard built to monitor daily chiller performance based on Excel reports received via Outlook. It helps operations and energy teams make data-driven decisions by visualizing key performance indicators such as:

- Coefficient of Performance (COP)
- Load Percentages
- Power Consumption Trends

This project was developed to automate daily reporting and bring clarity to operational data with easy-to-understand visuals.

---

## 🚀 Features

- ✅ Real-time updates from Excel reports received via Outlook
- 📈 SPC, Load %, and Power Trend visualizations
- 🔁 Scheduled refresh setup via Power BI Desktop
- 📊 Centralized and clean visual layout
- 📨 Email-to-dashboard automation workflow

---

## 🛠️ Tools & Technologies

- Power BI Desktop (.pbix)
- Excel
- Microsoft Outlook (for daily reports)
- Power Query
- Power Automate

## 📂 How to Use

1. Clone or download the repository.
2. Open `chiller_dashboard.pbix` in Power BI Desktop.
3. Edit the data source to match your local path for Excel reports.
4. Refresh the dashboard to visualize the latest data.

---

## 📅 Data Flow

1. Daily Excel report received in Outlook.
2. File saved to a specific local folder (manually or via Power Automate).
3. Power BI pulls and transforms the data using Power Query.
4. Dashboard is refreshed and visuals are updated.
